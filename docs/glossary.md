# Resume Analyzer SaaS — Glossary

## Purpose

This glossary defines the common business terminology used throughout the project.

Its goal is to establish a ubiquitous language so that developers, designers, and future contributors share the same understanding of the system.

---

## User

## Definition

A registered person who uses the platform to analyze and improve their resumes.

## Notes

- Owns one or more resumes.
- Can perform multiple analyses.
- Authenticates before accessing the application.

---

# Resume

## Definition

A professional resume owned by a user.

A resume represents a user's professional profile and serves as the primary input for resume analysis.

For the MVP, a resume stores only the latest uploaded PDF.

## Notes

A Resume is **not** just a PDF.

It also contains:

- Extracted text
- Structured resume information
- Metadata

---

# Structured Resume

## Definition

The structured representation of a resume generated after parsing the uploaded PDF.

## Purpose

Provides machine-readable information for the analysis engine.

## Example Contents

- Skills
- Experience
- Education
- Projects
- Certifications

---

# Raw Resume Text

## Definition

The plain text extracted directly from the uploaded PDF before any AI processing.

## Purpose

Acts as the source material for resume parsing.

---

# Job Description

## Definition

The job posting provided by the user during analysis.

For the MVP, it is treated as input to an Analysis rather than a standalone entity.

## Example

- Responsibilities
- Required Skills
- Preferred Qualifications
- Experience Requirements

---

# Parsed Job Description

## Definition

The structured representation of a job description generated during analysis.

## Example Contents

- Required Skills
- Preferred Skills
- Required Experience
- Education Requirements
- Keywords

---

# Analysis

## Definition

A historical snapshot comparing one Resume against one Job Description.

Each analysis preserves the results generated at a specific point in time.

## Notes

Analyses are immutable.

Once created, they are never modified.

---

# Match Score

## Definition

A numerical score indicating how well a resume aligns with a specific job description.

## Purpose

Provides an overall compatibility percentage.

## Example

82%

---

# ATS Score

## Definition

A score estimating how well the resume is optimized for Applicant Tracking Systems (ATS).

## Purpose

Highlights formatting and keyword optimization.

---

# Missing Keywords

## Definition

Important keywords or skills present in the job description but absent from the resume.

## Purpose

Helps users identify what recruiters or ATS systems may be expecting.

---

# Matching Keywords

## Definition

Keywords successfully identified in both the resume and the job description.

## Purpose

Shows the user's existing strengths and alignment with the target role.

---

# AI Suggestions

## Definition

Actionable recommendations generated by the AI engine to improve resume quality and job alignment.

## Examples

- Add measurable achievements.
- Highlight TypeScript experience.
- Include REST API projects.

---

# Resume Parsing

## Definition

The process of extracting and structuring information from an uploaded resume.

## Output

- Raw Text
- Structured Resume

---

# Job Description Parsing

## Definition

The process of extracting structured information from a job description.

## Output

- Skills
- Experience Requirements
- Education Requirements
- Keywords

---

# Analysis Engine

## Definition

The core business logic responsible for comparing a structured resume with a parsed job description.

## Responsibilities

- Calculate Match Score
- Calculate ATS Score
- Detect Missing Keywords
- Detect Matching Keywords
- Generate AI Suggestions

---

# Historical Analysis

## Definition

A previously completed analysis stored for future reference.

Historical analyses always represent the exact results generated at the time they were created.

They are never automatically recalculated.

---

# Immutable

## Definition

A property indicating that data cannot be modified after creation.

Example:

Analysis records are immutable.

---

# Mutable

## Definition

A property indicating that data may be updated during its lifecycle.

Example:

A Resume is mutable because users can upload a newer PDF.

---

# PDF Upload

## Definition

The process by which a user uploads a resume document for analysis.

Accepted format (MVP):

- PDF (.pdf)

---

# Resume History

## Definition

The collection of analyses previously performed on a resume.

For the MVP, this does **not** include resume version history.

Only analysis history is preserved.
